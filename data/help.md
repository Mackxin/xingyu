# 壹号栈 · 使用手册

> 一个自己用的导航站 + 分享簿 + 文章架。这里是 App 端的用法，都是本机数据，没有账号也不会联网同步到别处。

## 先认清三块地方

- **顶栏**：钉在最上面，不跟着页面滚。左边是站名「壹号栈」，右边是一排小按钮。
- **底栏**：悬浮在底部的那颗药丸，六个页签在这里换。
- **内容区**：中间那一大片，每个页签的内容都在这里。

## 顶栏怎么用

- **点「壹号栈」四个字**：滑到当前这一页的最底部，再点一下回到顶部。不管你在哪个页签上都一样，它不会把你送回首页。
- **搜索**：中间的搜索条，点开是整屏搜索，站点、分类、分享、文章一起搜。中文直接打，也能打拼音首字母 —— 输 `txsp` 出腾讯视频，输 `zh` 出知乎。
- **⌕ 筛选胶囊**：只在分享、文章、导航这三页出现，用来换标签或换分类。
- **自定义入口**：站名右边那一排小图标（比如 ✨ 灵感随记、👣 足迹），在网页端后台配，App 跟着显示，可以左右滑。
- **🕐 稍后读**：还没读的文章都在这儿，有未读数量角标。
- **🌙 / ☀️ 主题**：浅色深色一键切，也可以设成跟随系统。

## 底栏怎么用

六个页签：首页、分享、文章、导航、设置、收藏。

- **左右滑**内容区也能换页，跟点底栏一个效果，相邻的两页会跟着手指走。
- 想要图标：设置 → 底部标签栏 → 显示图标。
- 想换顺序或者藏起来：设置 → 底部标签栏 → 排序与显示，长按拖动，也可以把不用的页签关掉（设置页不能关）。

## 首页

- 大标题下面的四张卡是统计：分类、站点、分享、文章。
- 两张快捷卡直接去导航和文章。
- 「今日三站」是每天换的三个站点，同一个一天里不变，标题右边「换一批」可以再摇一次。
- 「今日精选」和「最近分享」是网页端后台挑的，App 每页显示几条也照后台的设置来。
- 底部的「在浏览器里打开网站」会跳出去，其余站内页面都在 App 里看。
- **首页哪些板块要显示**：设置 → 首页板块，开关一关再回首页就没了，还能用 ↑ ↓ 调顺序。

## 分享

- 按日期分组，一条一条往下看。
- 卡片上的标签可以点，点了就只看那个标签的内容。
- 顶上「筛选」点开是整屏的标签面板，同样一次铺满，不用滚。
- **长按卡片**：打开链接、复制链接、复制标题加链接。

## 标签页

点任何一个标签（分享卡片上的、文章底下的都行），会进到一个只属于这个标签的页面：上面写着这个标签下有几条分享、几篇文章，下面两段分别列出来。左上角返回就回去了。

## 文章

- 列表按年份分组，置顶的在最上面。
- 点进去是阅读页，左右滑就是上一篇 / 下一篇。
- 阅读页右下角两颗小圆：「回顶」和「目录」，长文章用目录跳着看。
- 阅读页顶栏有四个按钮：朗读、收藏、稍后读、分享。点喇叭整篇用系统语音念出来，再点一下停（走手机自带的文字转语音，不联网也能念；机器上没中文语音包会提示去系统设置装一个）。
- **长按任意一段**，底部弹出动作条：存为摘录 / 复制 / 朗读这一段。摘下来的都会进「摘录本」。
- **朗读的时候**，标题底下会多出一条：语速（0.8 / 1 / 1.25 / 1.5）和定时（15 / 30 / 60 分钟后自动停）。
  睡前听长文就靠这个，到点自己停，不会放一夜。
- **顶栏最右边那颗「⋯」**：把这篇存成 `.md` 文件（可以发到别的地方）、复制全文、或者扔到浏览器里看。
  存的是 Markdown 原文，不是排版后的网页，拿到笔记软件里还能改。
- 在设置里可以开「记住读到哪里」，下次点开还停在原处。
- 嫌字挤或者爱看疏的：设置 → 阅读 → 行距，紧凑 / 标准 / 宽松三档；字型也能换成衬线体（像纸书那种）。

## 导航

- 五十个分类、两千多个站点，往下滑会按分类分组显示。
- 顶上「全部分类」点开是整屏的分类面板：**所有分类一次铺满一屏，不用滚着找**，格子会自己缩到刚好装下。想更快就往面板顶上的筛选框里打几个字，选中一个面板自己就收了。
- 分类名后面的数字是这一类的站点数，一眼看出哪类内容多。
- 点分类名可以折叠或者展开；设置里能让它「进来先折叠」，一屏看到所有分类。
- 点一下站点就在 App 里打开，或者跳浏览器 —— 这个在设置 → 链接在 App 内打开里改。
- **长按站点**：收藏到本机、复制链接、标记失效。标了失效的会变灰加删除线，以后在设置 → 本机数据里能恢复。
- 页头那颗 **🎲 随便逛逛**：从两千多个站点里随便抽一个打开（已标失效的不参与）。不知道看啥的时候点它。
- **万物归一**那一类里除了站点，还挂着 App 自己的几页：灵感随记、本地音乐、**摘录本、站点巡检**。
  最后两个以前只能从设置里绕进去，现在跟别的入口摆在一起（设置里那两个还留着，两条路都通）。

## 收藏与稍后读

收藏页分三段：

- **文章收藏**：阅读页点那个星标加进来的。
- **文章稍后读**：阅读页点时钟加进来的，读完会自动从「稍后读」里消失。
  点时钟的那一刻，这篇的**正文会存一份到手机上** —— 以后站上撤了稿、或者你在设置里清了缓存，
  这条还在、点开还能读，不会变成一片空白。
- **站点收藏**：导航页长按站点加进来的。

这些全在本机，换手机带不走。

## 灵感随记

- 上面是写作框，写完点保存。**草稿会自动留着**，切走再回来还在。
- 支持 Markdown，也能直接写 `#标签`，会自动提取成标签。
- 卡片右上角三个点：置顶、存图（生成一张图分享出去）、复制、编辑、删除。
- 顶上还有：搜索、🎲 随机回顾、标签筛选、⚙ 标签管理（改名、删除）。
- 底部的「导出」可以导成 JSON 或 Markdown 文件，「导入」能把之前的 JSON 装回来。
- 工具条上还有「摘录 N」，点进去就是摘录本。
- **待整理**：在别的 App 里分享内容给壹号栈，会先摊在页头下面这块里。每条可以「写成随记」（变成一条灵感）、「收藏」（把里面的网址加进站点收藏，只在这条带网址时才出现）或者「删掉」。处理完这块自己就没了。

## 摘录本

阅读页长按存下来的段落都在这里（设置 → 我的内容 → 摘录本，或随记页工具条上的「摘录 N」）。

- 按文章归堆，上面写着出处，点出处就回原文。
- 每段底下四个动作：看原文、转随记（复制进灵感随记，摘录本身保留）、复制、删掉。
- 右上角垃圾桶能一次清空（转成随记的那几份不受影响）。
- 摘录只存这台手机，不跟着站点内容走，也不会被「同步内容」冲掉。

## 本地音乐

导航 → 万物归一 → **本地音乐**。这是 App 内置的一页（不是网页），歌存在手机里，不上传、不联网。

- **歌从哪来**：点右上角「＋ 选歌」，弹的是系统的文件选择器，可以一次挑好几首；
  或者进右边「⋮」菜单点 **扫本机音乐** —— 把手机里系统认得出的歌一次列出来，
  报个数、你点头才复制进来（第一次会问一次「读取音频」的权限）。
  App 会把音频**复制一份**进自己的私有目录 —— 之后你把手机里那些原文件删了，这里照样能放。
  扫过的歌不会重复加（按原始文件名 + 大小认）。
- **存在哪**：只在这台手机上，跟浏览器里那个网页版曲库是两份，互不相通。清 App 数据才会没。
- **封面和歌词**：mp3 / flac / m4a 里带的封面、歌手、歌词会自动读出来。
  歌词没内嵌的话，点「配歌词」，挑**同名**的 `.lrc` 文件，它会按文件名配上去
  （"夜航.mp3" 配 "夜航.lrc"；名字里的空格和大小写不用管）。
- **歌词怎么显示**：播放器上的「词」按钮。有 LRC 时间轴就一句一句跟着亮，
  点某句直接从那儿开始放；面板里只滚歌词，不带着整页跑。
  面板右上角 **整屏看**：字放大铺满一屏，躺着听也能看清，点右上角叉或返回键退回来。
- **歌单**：标题下面那一排胶囊，点「＋ 新建」起个名字（比如「通勤路上」），
  然后**长按任意一首歌** → 加入歌单。想从歌单里拿掉，就在这个歌单里长按那首歌 → 移出。
  长按歌单胶囊可以改名或删歌单（删歌单不动歌）。「全部 N」永远是整库。
- **睡眠定时**：播放器下面那一排 15 / 30 / 60 分。到点自动暂停（不是关掉），第二天点播放接着放。
- **列表**：每行左边封面、右边歌名和歌手，正在放的那首会变高亮并在右边显示暂停标。
  **长按某一行**出菜单：加入歌单 / 从当前歌单移出 / 删掉这首（会连复制进来的文件一起删，删前问一句）。
- **播放**：进度条能拖，上一首 / 下一首，左边的键在「顺序 → 单曲 → 随机」之间轮换。
  上一首有个常见手感：这首已经播了 3 秒以上，点上一首是回到开头，不是切歌。
- **切出去还在放**：App 用的是系统播放器 + 前台服务，退回桌面、锁屏都不会断，
  通知栏会常驻一条「上一首 / 暂停 / 下一首」，点一下就能控制，不用回 App。
  第一次进这一页会问一次通知权限 —— 不给也能放，只是通知栏看不到那条控制条。
- 离开这一页**不会**停播：它是个控制面板，不是播放开关；回来时进度和歌词位置都还在。

## 桌面小组件与快捷方式

- **小组件**：长按桌面空白处 → 小组件 → 找到壹号栈。显示今日三站，点某一行直接在 App 里打开那一站；
  底下那行是「待整理 / 稍后读 / 收藏」的条数。内容跟着 App 同步，每天换一批站点。
- **长按桌面图标**：多出三个快捷方式 —— 全站搜索、写随记、稍后读，不用先打开 App 再翻页。
- **从别处分享过来**：在任何 App 里点分享、选壹号栈，那段文字（和里面的网址）会落进「待整理」。

## 设置里有什么

- **外观**：跟随系统 / 浅色 / 深色。
- **阅读**：正文字号三档、行距三档、衬线 / 无衬线、记住读到哪里，以及**阅读页要不要留底栏**
  （默认不留，整屏看正文；打开后进文章也照样能直接切页签）。
- **列表**：卡片密度，紧凑一档一屏能多看两三条。
- **首页板块**：首页那九个板块哪个要显示、按什么顺序排。**长按一行直接拖动**就换位置
  （跟底栏排序一个手感）；关掉的排在下面那一截，重新打开会接在末尾，再拖上去。
- **导航**：进来先折叠、链接在 App 内打开。
- **底部标签栏**：显示图标、排序与显示。
- **启动**：打开 App 停在哪个页签。
- **内容更新**：打开时自动拉最新，切回 App（从后台回来）也会悄悄对一次，还能手动「立即同步」；
  下面显示上次同步时间、数据版本，以及**这次是从哪个域名拿到的**。
- **数据源**：两个里选一个当默认 —— **GitHub**（内置正式源）或**我的镜像**（你自己的虚拟主机）。
  选了镜像就先去问它，连不上再回落 GitHub；地址存着不删，什么时候切回来点一下就行。
  只填域名也认，会自动补成 `…/api/app.json`。
- **App 更新**：检查新版、下载、安装，可以设成只在 Wi-Fi 下下载。
- **存储**：离线缓存有多大，能一键清掉。
- **本机数据**：收藏、稍后读、失效标记、阅读记录、最近打开、最常去、每日计数，分别可以清。
- **我的内容**：摘录本（几段、点进去看/删/转随记）、站点巡检（随机抽 24 个站点真的敲一下，打不开的可以一键标「失效」，标过的卡片会淡下去；标错了在同一页能恢复）。
- **备份与恢复**：收藏、稍后读、随记、摘录、待整理、足迹、阅读进度和设置打成一份 JSON 导出；换手机时挑那份文件导入即可（合并进去，不覆盖现有的）。
- **使用手册**：就是你正在看的这一页。
- **版本更新**：每个版本改了什么，一条一条列着。

## 离线与更新

- 内容拉过一次之后就存在手机里，没网也能看，只是看不到新内容。
- 每次打开 App 会去拿一次最新的；从后台切回来也会对一次（一分钟内不重复拿，省流量）。
- 拿数据有好几个源排着队：**你自己的镜像 → GitHub Pages → GitHub 原始文件 → jsDelivr**，
  哪个先成功就用哪个。一个站不通不会卡住，后面还有备着的。
- 顶栏或者列表出现「离线」提示，就是这次全都没连上，看的还是上次那份。
- 想立刻刷新：设置 → 内容更新 → 立即同步（会给一句话，要么「已更新到最新」要么「已经是最新的了」）；
  或者在列表上下拉一下。
- 不管装的是哪一版 App，读的都是同一份 `api/app.json`。站点那边更新完，老版本也能拿到新内容
  （新版本才有的功能它不会长出来，但站点、文章、分享这些内容照旧是新的）。

## 常见问题

**点了站点没反应？**
可能是「链接在 App 内打开」开着，而那个站点禁止被嵌进别的应用。长按复制链接，粘到浏览器里就能开。

**为什么换手机收藏都没了？**
收藏、稍后读、灵感随记、阅读进度都存在这台手机上，没有云端账号，所以搬不过去。想保留就先导出 JSON。

**内容跟网页版不一样？**
App 读的是站点烘出来的那份 `api/app.json`，网页端改完要重新生成一次才会过来。
等一次自动同步，或者去设置里点「立即同步」。要是你从自己的虚拟主机读数据，记得那份文件也一起换掉。

**字太小 / 太大？**
设置 → 阅读 → 正文字号，三档里挑一个，下面那张预览卡会跟着变。
