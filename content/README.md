# content/ · 站点内容

这个目录就是站点内容的**唯一来源**。改这里的文件 = 改内容，不用开后台、不用导出。

改完之后：

```bash
node tools/build-content.js      # 只构建（顺便校验）
```

或者直接双击桌面「壹号栈 · 一键同步」—— 它会先跑上面这条，然后烘 app.json / feed.xml、推送、传镜像。

## 哪个文件管什么

| 文件 | 管什么 |
|---|---|
| `feed.json` | 「分享」页的时间线，一行一条，新的放最上面 |
| `posts/*.md` | 文章，一篇一个文件（`id` 默认取文件名） |
| `nav.json` | 导航分类与站点，一个分类一段、每条链接一行 |
| `site.json` | 站名、标语、首页文案、主题、阅读排版、关于页 |
| `entries.json` | 首页那几张快捷卡片 |

## 加一条分享

在 `feed.json` 的 `[` 后面粘一条，**最后一条不要逗号**，其余都要：

```json
  {"date": "2026-11-26", "icon": "🧩", "title": "标题",
   "url": "https://example.com", "desc": "一句话说明", "tags": ["工具"]},
```

- `url` 可以留空 → 变成一条点了不跳的纯文字卡（发公告好用）
- `desc` 里写 `\n\n` 是分段
- `date` 必须是 `2026-11-26` 这种格式

## 写一篇文章

新建 `posts/我的标题.md`：

```
---
title: 我的标题
date: 2026-11-26
tags: [工具, 前端]
excerpt: 列表页显示的一句话摘要
---

正文从这里开始，Markdown 全支持。
```

- `date` 必填，格式同上；`excerpt` 不写会自动取正文第一段
- 想换网址（默认是文件名）：加一行 `id: hello-xingyu`
- 置顶加 `pin: true`，草稿加 `draft: true`

## 改外观（站名 / 主题 / 首页文案）

这些也能先在后台 `#/admin` 里调（只在你这台机器上预览）。调满意了：
后台「发布上线」→ 点 **⬇ 导出 site.json** → 把下载到的 `site.json` 覆盖这个目录里的同名文件 → 同步。

## 写错了会怎样

构建会**先校验再写盘**，发现问题就点名文件和行号，并且一个字都不写 —— 线上还是上一版：

```
✗ content/ 里有 1 处写得不对：
  · feed.json：第 2 行 25 列 附近写错了（Expected ',' or '}' …）
```

常见原因：少了逗号、多了逗号、用了中文引号 `“ ”`、`date` 写成 `2026/1/1`。

## 别碰的东西

- `assets/js/site-data.js` —— 由这个目录烘出来的**产物**，手改下次构建就被覆盖
- `api/app.json`、`api/app.json.gz`、`feed.xml` —— 同样是产物

## 在手机 / 别的电脑上改

直接在 GitHub 网页打开 `content/feed.json` 编辑、提交，仓库里的 Actions 会自动跑一遍构建并发布（几分钟）。
