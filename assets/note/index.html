使用帮助

快速开始

  • 新建笔记：左上角「新建」，或按 Cmd/Ctrl + N
  • 粘贴即记：把内容直接粘进编辑器，右侧实时渲染 Markdown；粘贴较长内容时会提示一键新建笔记
  • 快捷工具栏：编辑器上方一键插入格式；电脑端还有删除线、有序列表、代码块、表格、分割线
  • 格式快捷键：编辑区聚焦时 Cmd/Ctrl+B 加粗、I 斜体、K 链接、Shift+X 删除线
  • 语音输入：右下角麦克风按钮，点击开始录音，识别文字插入笔记；优先用系统识别，不可用时自动切换离线引擎（首次加载约 30MB，之后秒开）
  • 自动保存：输入自动保存到浏览器本地，无需手动操作

视图与快捷键

  • 「编辑 / 分屏 / 预览」三种视图随时切换（Cmd/Ctrl + 1 / 2 / 3）
  • / 键：快速聚焦搜索；Esc：关闭所有弹窗
  • Cmd/Ctrl + S：立即保存并推送到云端；Tab 键：插入缩进
  • 列表导航：非输入状态下 ↑ / ↓ 切换笔记，Home / End 跳到首 / 尾笔记
  • 编辑区：F2 重命名、Cmd/Ctrl+Shift+D 删除当前笔记（有确认）、Cmd/Ctrl+Shift+A 开关多选
  • 重命名：双击顶部标题（或点铅笔图标）改名，回车保存；清空标题则恢复自动标题（取正文第一行）

整理与恢复

  • 置顶：悬停笔记出现图钉，点击置顶，重要笔记排最前
  • 标签：编辑区上方输入标签（如工作），回车添加；侧栏标签支持多选筛选，搜索框右侧可切换排序（最近更新 / 创建时间 / 标题）
  • 回收站：删除的笔记进入侧栏「回收站」，可恢复、彻底删除或一键清空
  • 批量：顶栏「多选」勾选多条笔记，可批量加标签或批量移入回收站
  • 备份与恢复：左下角「备份」导出完整 JSON；「从备份恢复」选择备份文件，按更新时间合并导入，不丢数据

GitHub 云同步

  • 点侧边栏「同步」或底部云朵图标，粘贴 token 连接
  • 全部笔记存进你自己的私有 Gist，自动同步；换设备、换域名用同一 token 连接即可找回原数据
  • Gist 地址、最近同步时间、远端数据查看都在同步面板里

数据查看与备份

  • 云端：同步面板 → Gist 地址（GitHub 网页）或「查看远端数据」（页内浏览）
  • 分享与打印：顶栏「分享」调起手机系统分享（电脑端为复制）；Cmd/Ctrl + P 直接打印当前笔记
  • 统计：左下角「统计」查看近 12 周每日写字量热力图、总字数与连续记录天数
  • 本地：右上角导出当前笔记 .md；左下角「备份」导出完整 JSON（含回收站与全部数据）；复制按钮可取 Markdown 原文

数据安全提示

  • 数据只存在你浏览器本地和你的私有 Gist，不经过任何第三方服务器
  • 换浏览器或清缓存前，建议先点左下角「备份」留一份完整数据
