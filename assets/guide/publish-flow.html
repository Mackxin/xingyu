YIHAOZHAN · 更新流程

后台改完，导出这一个文件

全站内容只有 content/site.json 一个文件：导航、分享、文章、外观都在里面。在后台改，导出它；想先看效果就丢给「本地预览」（不碰远端），满意了再拖给「拖文件上传」—— 网页 / App / 国内镜像一起新。

1先记住一件事

① 在后台改 导航 / 分享 / 文章 / 首页 / 主题，随便改。这时候只是本机草稿。
→
② 点「⬇ 导出 site.json」 下载到一个文件，全站内容都在里面，没有第二个文件要管。
③（可选）拖到「本地预览」看一眼 只校验、只烘、只在本机开个页面 —— 完全不碰远端。看完不满意就接着改。
→
④ 把 site.json 拖到「拖文件上传」 拷进仓库、校验、构建、推送、传镜像、核对。
⑤ 全端新了 网页 ⌘⇧R 强刷、App 切后台再回来。草稿在导出时就清掉了。
「后台改了，网站没变」不是 bug。后台保存的是草稿，前台永远读线上那份文件 —— 这是故意的：这样你才永远不会看到「本机一套、手机另一套」。要上线就走上面②③。

2三步（想先看效果就插一步）

  1. 改

    页脚 ⚙︎ 后台管理（口令 xingyu）→ 左边你要改的那一页。

    面板顶上会写「草稿里还有没发布的改动：导航 2081 条 · 分享 677 条」。看到这句就是还没发。

  2. 导出

    点左边最下面 💾 发布上线 → ⬇ 导出 site.json（全站内容）。下载夹里多一个 site.json。

    提示会念出来：已导出：2081 条链接 · 677 条分享 · 5 篇。

  3. （可选）本地先看一眼

    把下载夹里那个 site.json 拖到桌面 「壹号栈 · 本地预览」 上松手。 它只做三件事：校验 → 烘产物 → 在本机开个页面给你看。

    窗口里会写 「只看，不上线」，并念出条数。这一步不提交、不推送、不传镜像 —— 看完不满意就接着改，远端一点没动。

    如果你已经把文件覆盖进 content/site.json 了，直接双击这个图标就行，不用再拖一次。

  4. 拖到桌面图标

    满意了，把 site.json 拖到桌面 「壹号栈 · 拖文件上传」 上松手。

    窗口最后一行是 全部完成 ✓ —— 网页 / App / 国内镜像都已经是新内容。

不想拖也行：把 site.json 覆盖进仓库的 content/site.json，再双击桌面 「壹号栈 · 一键同步」。两条路做的是同一件事。
注意：覆盖文件本身不会让网站变 —— 站点读的是烘出来的 assets/js/site-data.js，不是 site.json。漏了「烘」这一步， 前台就一直是旧的。
改完想先在本机看？双击桌面「壹号栈 · 本地预览」，在它打开的那个地址 （127.0.0.1）上进后台改 —— 预览环境里前台直接读草稿， 切过去就是最新的，连导出都不用。左下角会挂一条「草稿预览」，提醒你这还不是线上。 满意了再回来导出、拖去上传。

3这一个文件里有什么

键管什么
site站名、标语、配色、首页文案、今日精选、关于页、赞助位
nav导航的分类与站点（50 个分类 / 2081 条链接）
feed「分享」页的时间线，一条一个对象
posts文章，一篇文章一个对象，body 是 Markdown 正文
entries首页那四张快捷卡片

想手改也行：加一条分享

粘在 feed 数组最前面，最后一条别忘了不加逗号。

{
  "date": "2026-11-26", "icon": "🧩", "title": "标题",
  "url": "https://example.com", "desc": "一句话说明", "tags": ["工具"]
},

写一篇文章

往 posts 数组里加一个对象。id 决定网址（#/post/<id>），改了 id 等于换网址。

{
  "id": "my-post", "title": "我的标题", "date": "2026-11-26",
  "tags": ["工具"], "excerpt": "列表页那句摘要",
  "body": "正文 Markdown 随便写。\n\n## 小标题\n\n- 一\n- 二"
},

4谁读哪个文件

文件谁在读要手改吗
content/site.json源头。脚本拿它烘下面三样只改这个
assets/js/site-data.js网页（导航 / 分享 / 文章 / 搜索）产物，别碰
api/app.json + .gz安卓 App 拉的数据产物，别碰
feed.xmlRSS 订阅器产物，别碰
所以「同步」这件事你不用理解：你只交一个文件，其余三样脚本现烘。烘坏了会当场拒发，线上还是上一版。

6命令速查（要动参数时才看）

命令做什么
python3 tools/sync.py一条做完：校验 → 构建 → 推送 → 传镜像 → 核对
python3 tools/sync.py --no-ftp只推 GitHub，不动镜像（出门在外用）
python3 tools/sync.py --dry只说会做什么，什么都不动
python3 tools/preview.py本地预览：校验 → 烘产物 → 本机开个页面，不碰远端
node tools/build-content.js --check只校验 site.json，不写文件
python3 tools/verify-ftp.py逐文件核对镜像（32 个全 ✓ 才算好）
python3 tools/upload-files.py 某文件补传单个文件（镜像掉了东西时用）

7三件别做的事

别手改 site-data.js它是产物，下次构建直接覆盖，白改。
别只传镜像不推 GitHub网页读的是 GitHub Pages，只传镜像 = 手机新、电脑旧。用同步脚本，它两边一起。
别在 content/site.json 里删键缺 nav 或 posts 会直接拒绝构建。要清空就给空数组 []。
